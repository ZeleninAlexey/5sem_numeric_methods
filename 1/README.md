# Запуск лабораторной 1

Нужен Python 3, дополнительные библиотеки не требуются. Выполняйте команды из этой папки.

```powershell
python main.py --task all --example
python main.py --task 3 --example --eps 1e-8
python main.py --task 2
```

`--task`: номер задания 1–5 или `all`; без параметра запускается задание 1.
`--example`: пример 10; без него вводите данные вручную.
`--eps`: точность итерационных методов, по умолчанию 1e-6.

Решения: [1.1](./lab1_1.py), [1.2](./lab1_2.py), [1.3](./lab1_3.py), [1.4](./lab1_4.py), [1.5](./lab1_5.py).
[main.py](./main.py) запускает задания, [numerics.py](./numerics.py) содержит общие вычисления; оба файла нужны для работы.
