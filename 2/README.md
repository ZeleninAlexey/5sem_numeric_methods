# Запуск лабораторной 2

Нужен Python 3, дополнительные библиотеки не требуются. Выполняйте команды из этой папки.

```powershell
python main.py --task all --example
python main.py --task 1 --eps 1e-8
python main.py --task 2
```

`--task`: номер задания 1, 2 или `all`; без параметра запускается задание 1.
`--eps`: точность вычислений. Без неё `--example` выбирает 1e-6, иначе программа запрашивает точность.
Во всех режимах используется вариант 10.

Решения: [2.1 — уравнение](./lab2_1.py), [2.2 — система](./lab2_2.py).
[main.py](./main.py) запускает задания, [numerics.py](./numerics.py) содержит общие функции; оба файла нужны для работы.
